# The book passport: decisions for a whole book

The passport holds what cannot be decided inside a single chunk and yet must be
decided the same way from beginning to end. Without it every chunk decides again —
and decides differently: the narrator is "I" in chapter three and "he" in chapter
seven, a character is addressed formally in one scene and familiarly in the next.

It is built by one call over the whole book: the model reads the entire text. The
button is in the "Ask the model" card on this page; when there is no passport yet,
that card is the whole of the screen.

## What is in it

**Kind and register.** Fiction or non-fiction, and what register it is written in:
neutral, elevated, colloquial.

**Narration.** Person (first, second, third) and tense (past, present).
Separately, the form of address — the familiar or the formal "you". English does
not make the distinction; a translation into a language that does makes it in
every line of dialogue, and it can only be settled from the book as a whole.

**Author.** Name and gender. Gender matters wherever the target language agrees
with it — and not only in a preface: it colours a narrator's voice when the
narrator stands close to the author.

**Characters.** Who acts, of what gender, and a dossier — what the book says about
them. The dossier reaches the translator along with the chunk that character
appears in, so the briefing differs from scene to scene.

**How direct speech is set.** Which mark opens a line in the target language: a
dash, quotation marks, guillemets. This is **set for the target language before
translating**, not read out of the text — the text does not exist yet.

**The point-of-view map.** Who narrates each chunk. Worked out from anchors plus a
prior on how narrators alternate, rather than by asking the model chunk by chunk,
which is measurably less reliable.

## Editing by hand

All of it can be corrected on this page. The model reads a book well but gets
things wrong — particularly the gender of minor characters and the form of
address.

Before rebuilding the passport, the previous one is set aside as a backup: hand
edits do not vanish quietly.

## The second route

Like the other whole-book calls, this one has "Build prompt" beside its button —
for a web console, where the window is bigger and no API key is needed. The answer
is pasted back and goes through the same checks.

## When to build it

Before translating. A passport built afterwards corrects nothing in the finished
text — the translator read the one that existed while it was working.

## What next

With a passport in place, go back to the monitor and run the translation.
